# Математическая модель платформы

Шесть слоёв спецификации плюс седьмой, добавленный платформой: контур индексации
заработной платы. Реализация — `syndicat/model/`, проверки — `tests/test_model.py`.

---

## Слой 1. Прибавочный продукт отрасли

Для класса ОКВЭД *j* и месяца *t*:

```
S_j(t) = V_j(t) − W_j(t) − D_j(t)
s_j(t) = S_j(t) / H_j(t)
```

`V` — валовая добавленная стоимость, `W` — оплата труда с начислениями,
`D` — потребление основного капитала, `H` — отработанные человеко-часы.

Раскладка на один человеко-час замкнута тождеством `v = w + d + s`
(`tests.TestAccountingIdentity`). Именно `s_j` сглаживается по экспоненте.

## Слой 2. Двойное экспоненциальное сглаживание (Хольт)

```
L_j(t) = α·s_j(t) + (1 − α)·[L_j(t−1) + T_j(t−1)]
T_j(t) = β·[L_j(t) − L_j(t−1)] + (1 − β)·T_j(t−1)
ŝ_j(t+1) = L_j(t) + T_j(t)
```

Коэффициенты задаются через полупериод, а не подбором:

```
α = 1 − 2^(−1/6)  = 0,1091      β = 1 − 2^(−1/12) = 0,0561
```

Поверх — механический ограничитель шага базы:

```
b_j(t) ∈ [0,98·b_j(t−1); 1,02·b_j(t−1)]
```

Смысл ограничителя не в точности, а в якорении ожиданий: правило опубликовано
заранее, поэтому внешний шок не разгоняет цены через ожидания участников.

## Слой 3. База токена человеко-часа

```
b_j = w_j + φ·ŝ_j
B   = Σ_j ω_j·b_j,   ω_j = H_j / ΣH
k_j = b_j / B
μ_j = [d_j + (1 − φ)·s_j] / b_j
```

Взвешивание **по часам, а не по обороту**: при взвешивании по выручке отрасль
с высокой капиталоёмкостью автоматически задавала бы курс всей сети.

Надбавка μ_j **выводится, а не назначается** — это и замыкает систему: величина,
которая в обычной корпорации является усмотрением инсайдера, здесь становится
следствием учётного тождества.

## Слой 4. Индивидуальная выработка

```
τ = [λ·T_факт + (1 − λ)·T_норм] · K_сл · K_цикл · q · k_j
K_сл   = (1 + γ)^(g−1),  γ = 0,125,  g = разряд 1-8
K_цикл = 1 + δ·ln(1 + D/D₀),  δ = 0,12,  D₀ = 30 дней
q < 0,90 → 0
```

**Расхождение в исходной спецификации.** Рядом с формулой `K_сл = (1 + γ)^(g−1)`
при γ = 0,125 указан диапазон «1,000 → 2,027». Фактически 1,125⁷ = **2,281**;
значение 2,027 соответствует γ = 0,1075. Платформа считает по опубликованному
уставному γ = 0,125 и показывает фактический диапазон в разделе «Модель и
параметры», чтобы расхождение было видно, а не сглажено. Если целью был диапазон
тарифных сеток ЕТКС (≈1 : 2,0), уставным параметром следует зафиксировать
γ = 0,1075.

## Слой 5. Цена продукта через полные трудозатраты

```
l_j = ψ_j / v_j                 прямые трудозатраты, чел.-ч на рубль выпуска
h   = l · (I − A)⁻¹             полные трудозатраты (обращение Леонтьева)
P_i = B · Σ_m [h_im · k_m · (1 + μ_m)] + E_i
R_i = (P_рыночная − P_производства) / P_рыночная
```

`E_i` — затраты вне периметра (сырьё ОКВЭД 05-09, энергия 35, транспорт 49-52)
по рыночному рублю: периметр открыт, и это отражено в цене честно.

Сходимость на сквозном примере (насос К100-65-200, ОКВЭД 28.13) — в пределах 2%.
Это не подтверждение правоты модели, а проверка замкнутости учётного тождества.

## Слой 6. Экстерналии и контур эмиссии

```
Δ ln P_i = Σ_k ε_ik · Δ ln X_k
ΔM_ТЧЧ(t) ≤ ΔQ_нормо-часов(t) · (1 + ρ),  ρ = 1,5% годовых
φ(t) = clip(φ − 0,5·(I − 1 ∓ 0,02), 0, 1)
```

Правило эмиссии ограничивает **прирост** массы токенов, а не её уровень: масса ТЧЧ
превышает фонд человеко-часов ровно настолько, насколько работа сложнее первого
разряда и длиннее опорного цикла. Панель показывает и отношение массы к фонду
времени, и допустимый месячный прирост.

## Слой 7. Индексация заработной платы в локальной корпоративной среде

Три контура, считаемые отдельно и складываемые:

```
ι_защ  = π                                    защитный: ИПЦ, ст. 134 ТК РФ
ι_пр   = θ · max(0; Δb_j − π)                 производительный, θ = 0,60
ι_перс = clip(ζ·(e_i/ē − 1); ±0,08)           персональный, ζ = 0,50
ι_i    = clip(ι_защ + ι_пр + ι_перс; π; 0,25)
```

где `Δb_j` — прирост базы часа за шаг индексации (12 месяцев) по траектории,
уже прошедшей сглаживание и ограничитель ±2%, а `e_i/ē` — относительная выработка:

```
e_i/ē = (K_сл(g)/K_сл(ḡ))^0,25 · (OEE/0,75)^0,5 · (q/0,975)²
```

Разряд уже оплачен тарифом, поэтому в персональный контур он входит в четвёртой
степени корня — как поправка, а не как второй тариф.

**Бюджетное ограничение шага:**

```
Σ_i W_i·ι_i ≤ F = φ · S_предприятия
```

Если потребность превышает фонд, надтарифная часть (производительный и
персональный контуры) умножается на общий коэффициент `scale < 1`. Защитный
контур не урезается никогда: это требование закона, а не параметр модели.
Если фонда не хватает даже на защитный контур, платформа показывает дефицит
и явно требует решения правления — источник вне социализируемого прибавочного
продукта.

**Почему так.** Индексация привязана не к решению собственника и не только
к инфляции, а к трём наблюдаемым величинам: индексу потребительских цен,
приросту базы часа (то есть отраслевой производительности, прошедшей сглаживание)
и фактической выработке. Все три публикуются вместе с отчётностью, поэтому спор
о размере индексации становится спором о данных, а не о доброй воле.
