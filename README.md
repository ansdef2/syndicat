# Синдикат — локальная платформа учёта ТЧЧ

Учётно-расчётный контур для группы промышленных предприятий периметра **ОКВЭД 2,
классы 20-30**: эмиссия токенов человеко-часов (ТЧЧ), ценообразование через полные
трудозатраты и индексация заработной платы в локальной корпоративной среде.

Платформа запускается **на локальной машине**, без внешних сервисов и без
зависимостей вне стандартной библиотеки Python.

```sh
./run.sh                 # либо python3 -m syndicat
# панель:   http://127.0.0.1:8777/
# API:      http://127.0.0.1:8777/api/overview
# выгрузка: http://127.0.0.1:8777/api/export/calibration.csv
```

Порт и адрес меняются флагами: `python3 -m syndicat --host 127.0.0.1 --port 9000`.

## Что внутри

| Раздел панели | Что показывает |
|---|---|
| **Обзор сети** | Курс ТЧЧ, отраслевая розетка k_j, индекс токен-цен в коридоре, труд и капитал в ВДС, глубина цепочек |
| **Токены человеко-часов** | Сравнительная диаграмма количественных и качественных показателей генерации, поле рассеяния, масса эмиссии, свод по предприятиям |
| **Сглаживание и база часа** | Двойное экспоненциальное сглаживание Хольта, траектория базы часа с ограничителем ±2% |
| **Ценообразование** | Восемь шагов образования цены изделия, каскад, разложение по отраслям-донорам, сценарий экстерналий |
| **Каналы субститутов** | Квантили цен, индекс замещаемости, правила публикации (k-анонимность, T+1) |
| **Реестр предприятий** | Средние и крупные субъекты периметра, капиталооборот, объём инфраструктуры, карточка предприятия с изделиями |
| **Индексация зарплаты** | Три контура индексации по разрядам, бюджетное ограничение φ·S, сравнение по сети |
| **Модель и параметры** | Уставные величины, шесть слоёв формул, границы применимости |

Глобальный ползунок **φ** (норма социализации прибавочного продукта) пересчитывает
всю модель на лету: база часа, коэффициенты, надбавки, цены и фонд индексации.

## Структура

```
syndicat/                ядро: только стандартная библиотека
  model/constants.py     уставные параметры и якорь калибровки
  model/industries.py    справочник ОКВЭД 20-30, матрица A, эластичности
  model/smoothing.py     Хольт + ограничитель шага
  model/tokens.py        слои 1-3: прибавочный продукт, база часа, эмиссия
  model/pricing.py       слои 4-6: Леонтьев, цена, экстерналии, контур эмиссии
  model/enterprises.py   реестр экономических субъектов
  model/costing.py       порядок образования цены изделия (8 шагов)
  model/indexation.py    индексация заработной платы
  model/analytics.py     витрины панели
  api.py, server.py      расчётное API и локальный HTTP-сервер
web/                     панель: HTML, CSS, ES-модули, SVG-диаграммы без библиотек
tests/test_model.py      33 проверки: тождества, калибровка, цена, индексация
docs/                    МОДЕЛЬ.md, ПРЕДПРИЯТИЯ.md, исходные документы
```

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Набор проверяет учётное тождество `V = W + D + S`, воспроизводимость опубликованной
калибровки (B = 876,58 руб./ТЧЧ), обращение Леонтьева, сквозной пример насоса
К100-65-200 (94,67 чел.-ч, цена производства 189 тыс. руб.), реакцию цен на сценарий
экстерналий и ограничения контура индексации.

## Данные

- **Отраслевые значения** — демонстрационная калибровка, воспроизводящая известную
  структуру отраслевых разрывов. Замещаются формами П-1, П-4 и таблицами
  «затраты-выпуск» на этапе 2 дорожной карты.
- **Предприятия** — наименования, регион и класс ОКВЭД фактические; численность,
  выручка, фонды, трудоёмкость и цены изделий модельные.
- **Якорь** — среднемесячная начисленная заработная плата по РФ 78 591,4 руб.
  (Росстат, январь-февраль 2026, предварительные данные).

## Шрифты и работа без сети

Панель подключает Unbounded и Golos Text с Google Fonts. Без доступа в интернет
подключение молча не срабатывает, и панель рисуется системными гротесками:
вёрстка, сетка и диаграммы от этого не страдают. Для полностью автономного
контура положите файлы шрифтов в `web/fonts/` и замените `<link>` в
`web/index.html` на локальное `@font-face`.
